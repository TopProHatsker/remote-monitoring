# Проверки

Проверки выполняются из корня проекта. Для разработки Python нужен Python 3.12:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install --require-hashes -r requirements-dev.txt
.venv/bin/python -m pytest -q
.venv/bin/ruff check app tests
```

Сборка клиента требует Node.js 22 и npm. В Docker они устанавливаются автоматически:

```sh
cd frontend
npm ci --ignore-scripts
npm run build
cd ..
docker build -t pc-monitor .
docker compose -f compose.yaml up -d
python3 tests/smoke.py
```

`tests/smoke.py` временно останавливает только Node Exporter этого проекта,
проверяет HTTP 503 и запускает сборщик обратно даже при провале проверки.
История не удаляется. Не запускайте эту проверку во время нужного непрерывного наблюдения.

Браузерные проверки открытого приложения:

```sh
cd frontend
npx playwright install chromium
npm test
```

Для другого адреса задайте `BASE_URL=http://<адрес>:<порт>`,
для установленного Chromium/Chrome — `BROWSER_EXECUTABLE=/путь/к/браузеру`.
Проверяются desktop, планшет и телефон, работа с виджетами, сохранение раскладки,
отказ API и восстановление, обе темы, создание числа/шкалы/графика с двумя рядами и полный экран с 5–24 виджетами без прокрутки, фиксированная сетка в клетках, точность перемещения после масштабирования, перенос прежней раскладки и расположение показаний в заголовках. Эмуляция размеров не заменяет проверку Safari на настоящем iPad.

В GitHub Actions выполняются тесты Python, линтер, сборка образа, запуск Compose,
проверка готовности, отказ сборщика и браузерные сценарии. Успешный локальный запуск
не заменяет зелёный CI для опубликованного коммита.
