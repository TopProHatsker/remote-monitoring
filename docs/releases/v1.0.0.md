# PC Monitor 1.0.0

Дашборд ресурсов Linux-хоста: CPU, память, диски, сеть и доступные температуры.
Числа, шкалы и графики настраиваются и сохраняются в браузере. Node Exporter
собирает метрики, Prometheus хранит историю за сутки, FastAPI отдаёт API и сайт.

В этой версии:

- Поле масштабируется реальными размерами сетки и Canvas, без растягивания готового изображения
- Числовое показание стоит в центре карточки; показания графика и шкалы выровнены справа и имеют размер заголовка
- Тёмная тема включена по умолчанию, явный выбор темы сохраняется
- В полном экране рамка скрыта, верхняя панель появляется поверх поля при наведении к верхнему краю; на touch достаточно коснуться края
- При потере сервера открытая вкладка сохраняет последние показания и восстанавливает обновление автоматически

Запуск и проверка готовности описаны в README. Нужны Linux, Docker Engine
и Docker Compose. Сервис рассчитан на доверенную локальную сеть.

Edge проверен на Linux при масштабе экрана 100%, 125%, 150% и 200%.
Проверка внешнего вида на Windows и Safari на физическом iPad остаётся за пользователем.
Поддержка Windows/macOS как измеряемого хоста, антисон, TLS и PWA не входят в эту версию.
