# PC Monitor 1.1.0

Дашборд ресурсов Linux-хоста: CPU, память, диски, сеть и доступные температуры.
Числа, шкалы и графики настраиваются и сохраняются в браузере. Node Exporter
собирает метрики, Prometheus хранит историю за сутки, FastAPI отдаёт API и сайт.

В этой версии:

- Поле автоматически подгоняется под границы карточек без изменения их координат
- В редакторе добавляются две клетки справа и снизу; новые карточки имеют размер 2×2
- Кнопка редактирования стоит перед «+ Виджет», размер поля показан только в редакторе
- График с двумя рядами показывает оба текущих значения и цвета линий; числа выровнены вправо, кружки центрированы, а общие колонки сохраняют ширину при опросах и расширяются только при необходимости
- Заголовки карточек выровнены по верху независимо от числа рядов; на узких карточках названия рядов скрыты
- Порог включается отдельным переключателем и по умолчанию выключен; значение и состояние сохраняются
- Включённый порог работает в единицах показателя, для обоих рядов, включая ноль и значения выше 100 вне процентной шкалы
- Выбранный период графиков сохраняется после перезагрузки страницы
- Подписи сетевого графика помещаются внутри Canvas, ширина оси учитывает длину текста
- Футеры всех карточек имеют одинаковый разделитель и равные отступы текста сверху и снизу
- В полном экране фон поля не отличается от страницы; сохранена поддержка Chrome 95 на Android

Запуск и проверка готовности описаны в README. Нужны Linux, Docker Engine
и Docker Compose. История метрик сохраняется в прежнем именованном томе.
Карточки, тема и значения порогов сохраняются; старые карточки без состояния
переключателя получают выключенный порог. Перед первой автоматической подгонкой
исходная раскладка сохраняется в отдельном ключе браузера.

Браузерные сценарии проверяют desktop, tablet и phone в Chromium. Физический
Android-планшет и Safari iPad в этом обновлении повторно не проверялись.
Поддержка Windows/macOS как измеряемого хоста, антисон, TLS и PWA не входят в эту версию.
