# PC Monitor

[![CI](https://github.com/TopProHatsker/remote-monitoring/actions/workflows/ci.yml/badge.svg)](https://github.com/TopProHatsker/remote-monitoring/actions/workflows/ci.yml)

Настраиваемый дашборд ресурсов Linux-компьютера: CPU, RAM, диски, сеть и доступные датчики. FastAPI отдаёт сайт и API, Node Exporter собирает метрики хоста, Prometheus хранит историю за последние сутки. Виджеты перемещаются и меняют размер в режиме редактирования; раскладка сохраняется в браузере. Светлая и тёмная темы оформлены в стиле «Витрина». Размер поля задаётся на верхней панели в клетках. Всё поле масштабируется под экран целиком без прокрутки; размеры и позиции карточек в клетках остаются одинаковыми в обычном и полноэкранном режиме. Клиент рассчитан на Android/Chrome и iPad/Safari. При отказе сервера уже открытая вкладка отмечает данные как устаревшие и восстанавливает обновление автоматически.

Для запуска нужны Linux, Docker Engine и Docker Compose. Python и Node на хосте не требуются. Из корня клона выполните команды ниже. Обязательного `.env` нет; порт сайта по умолчанию 8080. С телефона в той же сети откройте `http://<IP-компьютера>:8080`. Node Exporter использует пространства имён и read-only файловые системы хоста, слушает технический порт 9100; проект предназначен для доверенной локальной сети. Prometheus не публикует порт. Docker Desktop может измерять свою Linux-VM, а не физическую Windows/macOS-машину.

```sh
docker build -t pc-monitor .
docker compose up -d
curl --retry 30 --retry-all-errors --retry-delay 2 -fsS http://localhost:8080/health
docker compose ps
```

Проверка готовности: `/health` возвращает 200, только когда Prometheus доступен, сборщик успешно опрашивается и есть свежие базовые метрики; иначе 503. Проверить отказ можно через `docker compose stop node-exporter`, восстановление — `docker compose start node-exporter`. История находится в volume `history` и переживает обычные перезапуски; `docker compose down` останавливает проект без её удаления. В открытом дашборде доступны добавление, настройка, перемещение и удаление виджетов, выбор периода и полноэкранный режим при поддержке браузером. Настройки принадлежат конкретному браузеру и адресу сайта; первый запуск страницы без сервера, антисон и TLS не предусмотрены. Команды локальных и автоматических проверок приведены в [docs/testing.md](docs/testing.md).
